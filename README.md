# Legacy Penalty Kicks

A fun 3D penalty-kick game. Swipe up to shoot, curve your swipe to bend it, double-tap the ball to fake out the keeper.

Play it: turn on GitHub Pages (Settings > Pages > Deploy from branch > main / root), then open the link on the iPad.

On iPad: open the link in Safari, tap Share, then Add to Home Screen for a full-screen app.

Needs internet the first time it loads (3D library and fonts). Progress is saved on the device.
